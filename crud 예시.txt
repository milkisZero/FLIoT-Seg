서버 -> 클라
서버가 컨테이너 생성 -> mqtt 구독

클라 -> 서버
게이트웨이가 연결되면 자동으로 등록이 되지만, 그럼 서버가 먼저 실행되면 안됨





mqtt가 컨테이너에 등록
curl -X POST "http://192.168.0.60:7579/Mobius/KETI3_DEMO/myContainer" 
  -H "X-M2M-Origin: SOrigin" 
  -H "X-M2M-RI: 12345" 
  -H "Content-Type: application/json; ty=23" 
  -d '{
    "m2m:sub": {
      "rn": "testsub1",
      "nu": ["mqtt://192.168.0.60:1883/SFLIoT/led/set?ct=json"],
      "nct": 2,
      "enc": {
        "net": [1]
      }
    }
  }'

curl -X POST "http://192.168.0.60:7579/Mobius/FLIoT/myContainer" -H "X-M2M-Origin: SOrigin" -H "X-M2M-RI: 12345" -H "Content-Type: application/json; ty=23" -d "{\"m2m:sub\":{\"rn\":\"testsub1\",\"nu\":[\"mqtt://192.168.0.60:1883/SFLIoT/led/set?ct=json\"],\"nct\":2,\"enc\":{\"net\":[1,2,3,4]}}}"


구독한 것만 출력
curl -X GET "http://192.168.0.60:7579/Mobius?fu=1&ty=23"   -H "X-M2M-Origin: SOrigin"   -H "X-M2M-RI: 123456"   -H "Accept: application/json"

확인- 컨테이너에 데이터 추가
curl -X POST "http:/192.168.0.60:7579/Mobius/KETI3_DEMO/myContainer" \
  -H "X-M2M-Origin: SOrigin" \
  -H "X-M2M-RI: 12345" \
  -H "Content-Type: application/json; ty=4" \
  -d '{
    "m2m:cin": {
      "con": "Hello from Bash!"
    }
  }'

curl -X POST "http://192.168.0.60:7579/Mobius/FLIoT/myContainer" -H "X-M2M-Origin: SOrigin" -H "X-M2M-RI: 12345" -H "Content-Type: application/json; ty=4" -d "{\"m2m:cin\":{\"con\":\"Hello from Bash!\"}}"


컨테이너 만들기
curl -X POST "http://192.168.0.60:7579/Mobius/KETI3_DEMO" 
  -H "X-M2M-Origin: SOrigin" 
  -H "X-M2M-RI: 12345" 
  -H "Content-Type: application/json; ty=3" 
  -H "Accept: application/json" 
  -d '{
    "m2m:cnt": {
      "rn": "myContainer",
    }
  }'
curl -X POST "http://192.168.0.60:7579/Mobius/FLIoT" -H "X-M2M-Origin: SOrigin" -H "X-M2M-RI: 12345" -H "Content-Type: application/json; ty=3" -H "Accept: application/json" -d "{\"m2m:cnt\":{\"rn\":\"myContainer\"}}"
